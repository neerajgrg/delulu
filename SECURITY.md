# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of **Delulu** seriously. If you discover a security vulnerability, please do **NOT** open a public issue on GitHub.

Instead, please send an email directly to the project maintainers with:
- A description of the issue and potential impact
- Steps to reproduce or proof-of-concept
- Any relevant logs or code snippets

We will acknowledge receipt within 48 hours and work with you to resolve the vulnerability before any public disclosure.

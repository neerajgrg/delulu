Developer Documentation & Contributor Guide

Delulu is a specialized developer studio for authoring, evaluating, and deploying reusable skill packages across Claude, Gemini, Cursor, and Ollama agent runtimes.

Get Started in 60s Explore Skill Standard

1. Overview & Architecture Philosophy

AI agents are rapidly transitioning from simple chatbot prompts into autonomous executors with specific capabilities (skills). However, skill files are often scattered across proprietary folders (~/.claude/skills, .cursor/skills, ~/.gemini/skills) with zero version control, no linting, and no visibility into token consumption.

🎯 Single Source of Truth

Store skills centrally in ~/.delulu/skills and auto-symlink across every agent environment.

⚡ Real-Time Token Budgeting

Live BPE token counter and context window analyzer prevents prompt bloat and unnecessary latency.

🧪 Interactive Evals

Run real-time benchmark evaluations against local Ollama models or cloud LLMs prior to deployment.

2. Installation & Quick Start

Delulu runs seamlessly as a standalone desktop application via Electron or as a fast web IDE via Vite and Node.js.

# 1. Clone the repository
git clone https://github.com/neerajgrg/delulu.git
cd delulu
# 2. Install dependencies
npm install
# 3. Start Web IDE mode (Vite with Hot Module Replacement)
npm run dev:vite
# 4. Or start full Electron desktop app
npm run dev

3. Universal Skill Specification (.skill.md)

All skills in Delulu are standard Markdown documents with YAML frontmatter. This format is natively compatible with Claude Code, Cursor, Gemini, and MCP server standards: 

---
name: code-review
description: "Inspect code for quality, edge cases, and style improvements."
trigger: "review"
tags: [code, review, quality]
model: claude-3-5-sonnet-20241022
temperature: 0.7
max_tokens: 2048
---

# Code Review

## Description
Comprehensive code quality and security inspection agent skill.

## Examples

### Example 1
**Input:**
```typescript
function add(a, b) { return a + b; }
```

**Output:**
- ⚠️ Missing TypeScript type annotations for parameters `a` and `b`.
- ⚠️ Return type not declared — inferred as `any`.
- ✅ Logic is correct for numeric addition.

## Constraints
- Always provide actionable code diffs.
- Never output raw API keys or credentials.

4. Token Counting & Context Budgeting Engine

Delulu includes a native tokenizer analysis engine (src/lib/tokenCounter.ts) that computes:

⚡ Real-time Token Metrics

  • Exact character and BPE token density (3.2 chars/tok for code, 4.0 chars/tok for prose).
  • Section breakdown (Frontmatter vs Examples vs Constraints).

📊 Context Window Consumption

  • Percentage calculation against standard 128k/200k agent context windows.
  • Estimated cost per 1k invocations to manage LLM inference budgets.
